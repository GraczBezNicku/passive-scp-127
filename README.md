# Passive SCP-127
This plugin allows SCP-127 to talk to nearby humans when not picked up. It will greet oncoming humans, converse with them if they stand nearby long enough, and call out to them if they leave without SCP-127.
# Configuration
You can change the following values within the default config:
- Interval at which each SCP-127 instance checks for humans
- Radius at which humans are searched for
- How much time needs to pass for SCP-127 to idle talk with humans
- Voicelines for greeting, abandoning and idle
